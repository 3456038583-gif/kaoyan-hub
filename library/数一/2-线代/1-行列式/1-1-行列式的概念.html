#线代 #行列式

行列式的三种定义

几何定义

  • 二阶行列式 ∣a11a12a21a22∣\begin{vmatrix}a_{11}&a_{12}\\a_{21}&a_{22}\end{vmatrix}​a11​a21​​a12​a22​​​ 是由两个二维向量组成的，其值的绝对值是以这两个向量为邻边的平行四边形的面积；三阶行列式是由三个三维向量组成的，其值的绝对值是以这三个向量为邻边的平行六面体的体积。
  • nnn 阶阶行列式 Dn=∣a11⋯a1n⋮⋮an1⋯ann∣D_n=\begin{vmatrix}a_{11}&\cdots&a_{1n}\\\vdots&&\vdots\\a_{n1}&\cdots&a_{nn}\end{vmatrix}Dn​=​a11​⋮an1​​⋯⋯​a1n​⋮ann​​​ 是由 nnn 个 nnn 维向量 a1=[a11a12⋯ ,a1n],⋯ ,an=[an1,an2,⋯ ,ann]a_1=\begin{bmatrix}a_{11}&a_{12}&\cdots,a_{1n}\end{bmatrix},\cdots,a_{n}=[a_{n1},a_{n2},\cdots,a_{nn}]a1​=[a11​​a12​​⋯,a1n​​],⋯,an​=[an1​,an2​,⋯,ann​] 组成的,其结果是以这 n个向量为邻边的 nnn 维图形的有向体积。
  • 重要推论：若 n 阶行列式的值为 0，则其行（或列）向量组线性相关；反之，若不为 0，则线性无关。

逆序数法定义

  • 在一个排列中，排在某数前面的比它大的数的个数，称为该数的逆序数。排列中所有数的逆序数之和称为该排列的逆序数，记为 τ\tauτ。逆序数为奇数的排列为奇排列，为偶数的为偶排列。
  • Dn=∣a11⋯a1n⋮⋮an1⋯ann∣=∑j1j2⋯jn(−1)τ(j1j2⋯jn)a1j1a2j2⋯anjnD_n=\begin{vmatrix}a_{11}&\cdots&a_{1n}\\\vdots&&\vdots\\a_{n1}&\cdots&a_{nn}\end{vmatrix}=\sum_{j_{1}j_{2}\cdots j_{n}}(-1)^{\tau(j_{1}j_{2}\cdots j_{n})}a_{1j_{1}}a_{2j_{2}}\cdots a_{nj_{n}}Dn​=​a11​⋮an1​​⋯⋯​a1n​⋮ann​​​=∑j1​j2​⋯jn​​(−1)τ(j1​j2​⋯jn​)a1j1​​a2j2​​⋯anjn​​
    • n 阶行列式是 n!n!n! 项的代数和，每一项都是取自不同行、不同列的 n 个元素的乘积，其正负号由列下标排列的奇偶性决定。

降阶定义

定义： #余子式

描述：MijM_{ij}Mij​ 在 n 阶行列式中，划去元素 aija_{ij}aij​ 所在的第 i 行和第 j 列后，剩下的元素按原序构成的 n-1 阶行列式。

定义： #代数余子式

描述：Aij=(−1)i+jMijA_{ij}=(-1)^{i+j}M_{ij}Aij​=(−1)i+jMij​。

定理： #展开定理

描述：行列式的值等于其任意一行（列）的各元素与其对应的代数余子式乘积之和。

  • 按行展开：∣A∣=∑j=1naijAij(i=1,2,…,n)|A| = \sum_{j=1}^{n}a_{ij}A_{ij} \quad (i=1, 2, \dots, n)∣A∣=∑j=1n​aij​Aij​(i=1,2,…,n)
  • 按列展开：∣A∣=∑i=1naijAij(j=1,2,…,n)|A| = \sum_{i=1}^{n}a_{ij}A_{ij} \quad (j=1, 2, \dots, n)∣A∣=∑i=1n​aij​Aij​(j=1,2,…,n)

某行（列）的元素与另一行（列）对应元素的代数余子式乘积之和等于 0。
