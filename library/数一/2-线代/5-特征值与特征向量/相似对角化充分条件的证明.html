相似对角化充分条件的证明

情况一：幂等矩阵 A2=AA^2=AA2=A（特征值为 0 或 1）

证明：

由 A2=A⇒A2−A=0⇒A(A−E)=0A^2=A \Rightarrow A^2-A=0 \Rightarrow A(A-E)=0A2=A⇒A2−A=0⇒A(A−E)=0，可知特征值满足 λ2−λ=0\lambda^2-\lambda=0λ2−λ=0，即 λ=0\lambda=0λ=0 或 λ=1\lambda=1λ=1。

  1. 对于 λ=0\lambda=0λ=0： 解 Ax=0A\boldsymbol{x}=\boldsymbol{0}Ax=0
    线性无关特征向量个数为：n−r(A)n - r(A)n−r(A)

  2. 对于 λ=1\lambda=1λ=1： 解 (E−A)x=0(E-A)\boldsymbol{x}=\boldsymbol{0}(E−A)x=0
    线性无关特征向量个数为：n−r(E−A)n - r(E-A)n−r(E−A)

关键步骤： 证明 r(A)+r(E−A)=nr(A) + r(E-A) = nr(A)+r(E−A)=n

由 A(E−A)=A−A2=OA(E-A) = A - A^2 = OA(E−A)=A−A2=O，根据 Sylvester 不等式：

r(A)+r(E−A)≤nr(A) + r(E-A) \leq nr(A)+r(E−A)≤n

又由秩不等式 r(A)+r(E−A)≥r(A+E−A)=r(E)=nr(A) + r(E-A) \geq r(A + E - A) = r(E) = nr(A)+r(E−A)≥r(A+E−A)=r(E)=n

因此：

r(A)+r(E−A)=nr(A) + r(E-A) = nr(A)+r(E−A)=n

结论： 矩阵 AAA 有 [n−r(A)]+[n−r(E−A)]=2n−[r(A)+r(E−A)]=2n−n=n[n-r(A)] + [n-r(E-A)] = 2n - [r(A)+r(E-A)] = 2n - n = n[n−r(A)]+[n−r(E−A)]=2n−[r(A)+r(E−A)]=2n−n=n 个线性无关的特征向量。

故 ** AAA 可相似对角化**。

情况二：对合矩阵 A2=EA^2=EA2=E（特征值为 ±1\pm 1±1）

证明：

由 A2=E⇒A2−E=0⇒λ2−1=0A^2=E \Rightarrow A^2-E=0 \Rightarrow \lambda^2-1=0A2=E⇒A2−E=0⇒λ2−1=0，即 λ=1\lambda = 1λ=1 或 λ=−1\lambda = -1λ=−1。

  1. 对于 λ=1\lambda=1λ=1： 解 (E−A)x=0(E-A)\boldsymbol{x}=\boldsymbol{0}(E−A)x=0
    线性无关特征向量个数为：n−r(E−A)n - r(E-A)n−r(E−A)

  2. 对于 λ=−1\lambda=-1λ=−1： 解 (E+A)x=0(E+A)\boldsymbol{x}=\boldsymbol{0}(E+A)x=0
    线性无关特征向量个数为：n−r(E+A)n - r(E+A)n−r(E+A)

关键步骤： 证明 r(E−A)+r(E+A)=nr(E-A) + r(E+A) = nr(E−A)+r(E+A)=n

由 (E−A)(E+A)=E−A2=O(E-A)(E+A) = E - A^2 = O(E−A)(E+A)=E−A2=O，得：

r(E−A)+r(E+A)≤nr(E-A) + r(E+A) \leq nr(E−A)+r(E+A)≤n

又由 r(E−A)+r(E+A)≥r[(E−A)+(E+A)]=r(2E)=nr(E-A) + r(E+A) \geq r[(E-A)+(E+A)] = r(2E) = nr(E−A)+r(E+A)≥r[(E−A)+(E+A)]=r(2E)=n

因此：

r(E−A)+r(E+A)=nr(E-A) + r(E+A) = nr(E−A)+r(E+A)=n

结论： 矩阵 AAA 有 [n−r(E−A)]+[n−r(E+A)]=2n−[r(E−A)+r(E+A)]=2n−n=n[n-r(E-A)] + [n-r(E+A)] = 2n - [r(E-A)+r(E+A)] = 2n - n = n[n−r(E−A)]+[n−r(E+A)]=2n−[r(E−A)+r(E+A)]=2n−n=n 个线性无关的特征向量。

故 ** AAA 可相似对角化**，且相似于对角矩阵 (ErOO−En−r)\begin{pmatrix} E_r & O \\ O & -E_{n-r} \end{pmatrix}(Er​O​O−En−r​​)，其中 r=r(E−A)r = r(E-A)r=r(E−A)。

推广：极小多项式无重根

定理： 若矩阵 AAA 满足 A2−(λ1+λ2)A+λ1λ2E=OA^2 - (\lambda_1+\lambda_2)A + \lambda_1\lambda_2 E = OA2−(λ1​+λ2​)A+λ1​λ2​E=O（即极小多项式为 m(λ)=(λ−λ1)(λ−λ2)m(\lambda)=(\lambda-\lambda_1)(\lambda-\lambda_2)m(λ)=(λ−λ1​)(λ−λ2​)，有两个不同根），则 AAA 可相似对角化。

证明思路：

  • 证明 (λ1E−A)(λ2E−A)=O(\lambda_1 E - A)(\lambda_2 E - A) = O(λ1​E−A)(λ2​E−A)=O
  • 证明 r(λ1E−A)+r(λ2E−A)=nr(\lambda_1 E - A) + r(\lambda_2 E - A) = nr(λ1​E−A)+r(λ2​E−A)=n
  • 从而两个特征子空间维数之和为 nnn，几何重数等于代数重数
