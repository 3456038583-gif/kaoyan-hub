5-4 实对称矩阵

#线代 #特征值与特征向量 #实对称矩阵 别名：实对称矩阵、2 实对称矩阵

性质

  1. nnn 阶实对称矩阵 AAA 有 nnn 个实的特征值，也必有个线性无关的特征向量，且矩阵 AAA 的几何重数等于代数重数，故实对称矩阵必可相似对角化
  2. 实对称矩阵对应于不同的特征值的特征向量必是正交的（比线性无关更强），即 λ1≠λ2\lambda_1 \ne \lambda_2λ1​=λ2​ 时，有 (x1,x2)=x1Tx2=0(\mathbf{x}_1, \mathbf{x}_2) = \mathbf{x}_1^T \mathbf{x}_2 = 0(x1​,x2​)=x1T​x2​=0，正交矩阵
  3. nnn 阶实对称矩阵 AAA 不但可以相似对角化，也可以正交相似对角化（用正交矩阵 PPP）。
  4. 能够正交相似对角化的实矩阵也一定是实对称矩阵。也即存在正交矩阵 QQQ，使得
Q−1AQ=QTAQ=Λ Q^{-1}AQ = Q^T AQ = \Lambda Q−1AQ=QTAQ=Λ
