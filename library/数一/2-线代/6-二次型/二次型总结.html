矩阵合同

定义

两个 nnn 阶实对称矩阵 AAA 和 BBB，如果存在可逆矩阵 CCC，使得 B=CTACB = C^T A CB=CTAC，则称 AAA 和 BBB 合同 (Congruent)，记作 A≃BA \simeq BA≃B。

笔记

两个二次型可以用可逆线性变量替换互相转化的充要条件是它们的矩阵合同。

合同的性质

  1. 反身性：A≃AA \simeq AA≃A。
  2. 对称性：若 A≃BA \simeq BA≃B，则 B≃AB \simeq AB≃A。
  3. 传递性：若 A≃B,B≃CA \simeq B, B \simeq CA≃B,B≃C，则 A≃CA \simeq CA≃C。
  4. 若 A≃BA \simeq BA≃B，则 r(A)=r(B)r(A) = r(B)r(A)=r(B) (合同变换不改变秩)。

实对称矩阵合同的判别

两个实对称矩阵 AAA 和 BBB 合同的充要条件是它们有相同的正惯性指数和相同的负惯性指数 (或相同的秩和正惯性指数)。

二次型的标准化

将二次型化为标准形 (即矩阵化为对角矩阵) 的两种主要方法：

1. 正交变换法

  • 原理：对于实对称矩阵 AAA，必存在正交矩阵 QQQ，使得 Q−1AQ=QTAQ=ΛQ^{-1} A Q = Q^T A Q = \LambdaQ−1AQ=QTAQ=Λ。
  • 步骤：
    1. 求出 AAA 的所有特征值 λ1,⋯ ,λn\lambda_1, \cdots, \lambda_nλ1​,⋯,λn​。
    2. 求出对应的特征向量，并进行施密特正交化和单位化，构造正交矩阵 QQQ。
    3. 作变换 X=QYX = QYX=QY。
  • 结果：标准形为 f=λ1y12+λ2y22+⋯+λnyn2f = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \cdots + \lambda_n y_n^2f=λ1​y12​+λ2​y22​+⋯+λn​yn2​。
  • 特点：系数 λi\lambda_iλi​ 是 AAA 的特征值。AAA 与 Λ\LambdaΛ 既相似又合同。

2. 配方法 (拉格朗日配方法)

  • 原理：利用初等变换 (可逆线性变换) 将二次型化为平方和形式。
  • 步骤：
    1. 若含平方项 xi2x_i^2xi2​，将所有含 xix_ixi​ 的项归并，配成完全平方。
    2. 若不含平方项但含 xixjx_i x_jxi​xj​，先作变换 xi=yi+yj,xj=yi−yjx_i = y_i + y_j, x_j = y_i - y_jxi​=yi​+yj​,xj​=yi​−yj​ 制造平方项，再配方。
  • 特点：CCC 仅为可逆矩阵。AAA 与对角阵 DDD 合同但不一定相似。标准形的系数不是特征值。
