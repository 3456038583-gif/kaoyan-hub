矩阵合同

  • 定义：
    • 设有两个 nnn 阶矩阵 A,BA, BA,B，如果存在一个可逆 nnn 阶矩阵 CCC，使 CTAC=BC^T AC = BCTAC=B，则称矩阵 AAA 与 BBB 合同，
    • 若 AAA 为对称矩阵，则 BBB 也是对称矩阵。因此实对称矩阵不可能与非对称矩阵合同
  • 性质：
    • 反身性: AAA 与自身合同，显然 ETAE=AE^T AE = AETAE=A;
    • 对称性: 若 AAA 与 BBB 合同，则 BBB 与 AAA 合同；
    • 传递性: 若 AAA 与 DDD 合同，BBB 与 DDD 合同，则 AAA 与 BBB 合同；
    • 特别地，若通过正交变换 QTAQ=BQ^T AQ = BQTAQ=B，则 AAA 与 BBB 既合同，又相似；实对称矩阵
    • 矩阵 AAA 与 BBB 合同，则 AAA 与 BBB 秩相等。规范型相同。
  • 合同的充分必要条件：

      合同的充要条件

      两个二次型（或实对称矩阵）合同的充要条件是

      • 有相同的正、负惯性指数
      • 有相同的秩及正（或负）惯性指数
      • 有相同的正、负特征值个数.

惯性定理

  • 定义：

    • 无论选取什么样的可逆线性变换，将二次型 f(x1,x2,⋯ ,xn)=xTAxf(x_1, x_2, \cdots, x_n) = \mathbf{x}^T A \mathbf{x}f(x1​,x2​,⋯,xn​)=xTAx 化成标准形或规范形，其正项个数 ppp，负项个数 qqq 都是不变的。ppp 称为正惯性指数，qqq 称为负惯性指数。
    • 本质：合同于实对称矩阵的规范形对角矩阵是唯一的，即正惯性指数 ppp 和负惯性指数 qqq 由矩阵本身唯一确定，与所用的可逆变换无关，类似于物体的“惯性”不依懒外界条件。

  • 结论

    • p+q=r(A)p+q=r(A)p+q=r(A)，即正负惯性指数之和与矩阵 AAA 的秩相等；
    • 二次型的规范形是唯一确定的 (不考虑系数的排序)；
    • 两个同阶实对称矩阵 AAA 与 BBB 合同 ⇔\Leftrightarrow⇔ 规范形相同 ⇔\Leftrightarrow⇔ 正、负惯性指数相等 ⇔A,B\Leftrightarrow A, B⇔A,B 的秩和正惯性指数相同；

      • 有相同的正、负特征值个数.
