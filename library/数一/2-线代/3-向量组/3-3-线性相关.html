n+1n+1n+1 个 nnn 维向量一定线性相关。又有 r(Am×n)≤min⁡{m,n}r(A_{m\times n})\le \min\{m,n\}r(Am×n​)≤min{m,n}。

性质

  1. 若向量组 a1,a2,⋯ ,ana_1,a_2,\cdots,a_na1​,a2​,⋯,an​ 线性无关，而 β,a1,a2,⋯ ,an\beta,a_1,a_2,\cdots,a_nβ,a1​,a2​,⋯,an​ 线性相关，则 β\betaβ 可由 a1,a2,⋯ ,ana_1,a_2,\cdots,a_na1​,a2​,⋯,an​ 线性表示，且表示法唯一。
  2. 部分组相关，则整体组相关；反之不成立。
  3. 整体组无关，则任意部分组无关；反之不成立。
  4. 线性无关向量组延伸后仍可保持线性无关。
  5. 缩短后的向量组若线性相关，则原组也相关。
  6. 若一组向量可由另一组线性表示，且前者个数更多，则前者线性相关，可记为“以少表多，多的相关”。
引用

两个向量相关意味着共线，三个向量相关常对应共面。
