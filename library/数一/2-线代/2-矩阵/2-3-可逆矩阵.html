2-3 可逆矩阵

#线代 #矩阵 #可逆矩阵 别名：可逆矩阵

定义

设 A 是 n 阶矩阵, 如果存在 n 阶矩阵 B 使得

AB=BA=E(单位矩阵) AB = BA = E(单位矩阵) AB=BA=E(单位矩阵)
成立, 则称 A 是可逆矩阵或非奇异矩阵, B 是 A 的逆矩阵, 记成 A−1=BA^{-1} = BA−1=B.

若 A 可逆, 则 A 的逆矩阵唯一. A 可逆 ⇔∣A∣≠0\Leftrightarrow |A| \neq 0⇔∣A∣=0. 设 A 和 B 是 n 阶矩阵且 AB = E, 则 BA = E.

n 阶矩阵 A 可逆的充分必要条件

n 阶矩阵 A 可逆的充分必要条件
  1. 存在 n 阶矩阵 B, 使 AB=EAB = EAB=E (或 BA=EBA = EBA=E).
  2. ∣A∣≠0|A| \neq 0∣A∣=0, 或秩 r(A)=nr(A) = nr(A)=n, 或 A 的列 (行) 向量线性无关.
  3. 齐次方程组 Ax=0Ax = 0Ax=0 只有零解.
  4. ∀b\forall b∀b, 非齐次线性方程组 Ax=bAx = bAx=b 总有唯一解.
  5. 矩阵 A 的特征值全不为 0.

逆矩阵的运算性质

  • 若 k≠0k \neq 0k=0, A 可逆, 则 (kA)−1=1kA−1(kA)^{-1} = \frac{1}{k}A^{-1}(kA)−1=k1​A−1.
  • 若 A, B 可逆, 则 (AB)−1=B−1A−1(AB)^{-1} = B^{-1}A^{-1}(AB)−1=B−1A−1, 特别地 (A2)−1=(A−1)2(A^2)^{-1} = (A^{-1})^2(A2)−1=(A−1)2.
  • 若 ATA^TAT 可逆, 则 (AT)−1=(A−1)T(A^T)^{-1} = (A^{-1})^T(AT)−1=(A−1)T; (A−1)−1=A(A^{-1})^{-1} = A(A−1)−1=A; ∣A−1∣=1∣A∣|A^{-1}| = \frac{1}{|A|}∣A−1∣=∣A∣1​.
  • AB=BA=EAB=BA=EAB=BA=E

注意 即使 A, B 和 A+B 都可逆, 一般地 (A+B)−1≠A−1+B−1(A+B)^{-1} \neq A^{-1} + B^{-1}(A+B)−1=A−1+B−1.

(A−1+B−1)−1=A(A+B)−1B=B(A+B)−1A(A^{-1}+B^{-1})^{-1} = A(A+B)^{-1}B = B(A+B)^{-1}A(A−1+B−1)−1=A(A+B)−1B=B(A+B)−1A

判断是否可逆

  1. 行列式不为 0
  2. 构造等式，使 AB=E\displaystyle AB=EAB=E 或 BA=EBA=EBA=E, 则 A 可逆, 且 A−1=BA^{-1}=BA−1=B
  3. 特征值与特征向量，特征值不含 0
  4. 分块，不成比例

求逆矩阵的方法

  • 方法一 用公式, 若 ∣A∣≠0|A| \neq 0∣A∣=0, 则 A−1=1∣A∣A∗\displaystyle A^{-1} = \frac{1}{|A|}A^*A−1=∣A∣1​A∗.
  • 方法二 初等变换法. (A∣E)→初等行变换(E∣A−1)\displaystyle(A \mid E) \xrightarrow{初等行变换} (E \mid A^{-1})(A∣E)初等行变换​(E∣A−1).
  • 方法三 用定义求 B, 使 AB=E\displaystyle AB=EAB=E 或 BA=EBA=EBA=E, 则 A 可逆, 且 A−1=BA^{-1}=BA−1=B. 或令 A=BC，则A−1=C−1B−1A=BC，则A^{-1}=C^{-1}B^{-1}A=BC，则A−1=C−1B−1。往往需要用到各种变形、平方、乘积
  • 方法四 用分块矩阵.
