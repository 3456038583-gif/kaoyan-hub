AB=O的思考

#线代 #矩阵 #秩 别名：AB=O的思考

A - m×nm \times nm×n, B - n×sn \times sn×s, 如 AB=OAB=OAB=O，则 r(A)+r(B)≤nr(A)+r(B) \le nr(A)+r(B)≤n

另外理解：

  1. B 的列向量是 AX=OAX=OAX=O 的解，基础解系证明
  2. 矩阵 BBB 的每一列 (非零向量) 均为 AAA 的属于 λ=0\lambda=0λ=0 的特征向量.
  3. A 的列向量线性相关
  4. A 为方阵时，∣A∣=0|A|=0∣A∣=0
  5. A 有 0 特征值
  6. Sylvester不等式

  1. Ax=0Ax = 0Ax=0 : n−r(A)n-r(A)n−r(A) 个无关的解向量, {β1,β2,…,βs}⊂{AX=0 解向量}\{\beta_1, \beta_2, \ldots, \beta_s\} \subset \{AX = 0 \text{ 解向量}\}{β1​,β2​,…,βs​}⊂{AX=0 解向量}
r(β1,β2,…,βs)≤n−r(A),∴r(A)+r(B)≤nr(\beta_1, \beta_2, \ldots, \beta_s) \leq n-r(A), \quad \therefore \quad r(A) + r(B) \leq nr(β1​,β2​,…,βs​)≤n−r(A),∴r(A)+r(B)≤n

伴随矩阵秩的讨论：

① 若 r(A)=nr(A) = nr(A)=n，则 ∣A∣≠0|A| \neq 0∣A∣=0，∣A∗∣=∣A∣n−1≠0|A^*| = |A|^{n-1} \neq 0∣A∗∣=∣A∣n−1=0，⇒r(A∗)=n\Rightarrow r(A^*) = n⇒r(A∗)=n

② 若 r(A)=n−1r(A) = n-1r(A)=n−1，由 AA∗=A∗A=∣A∣E=OAA^* = A^*A = |A|E = OAA∗=A∗A=∣A∣E=O

③ 若 r(A)<n−1r(A) < n-1r(A)<n−1，则 A∗=OA^* = OA∗=O，r(A∗)=0r(A^*) = 0r(A∗)=0

由 ②：r(A)+r(A∗)≤nr(A) + r(A^*) \leq nr(A)+r(A∗)≤n，即 (n−1)+r(A∗)≤n(n-1) + r(A^*) \leq n(n−1)+r(A∗)≤n，故 r(A∗)≤1r(A^*) \leq 1r(A∗)≤1
