2-1 矩阵的基本概念

#线代 #矩阵

矩阵的定义

  • 定义：
    • 由 m×nm \times nm×n 个数排成的 mmm 行 nnn 列的矩形表格，记作 A=(aij)m×nA=(a_{ij})_{m \times n}A=(aij​)m×n​。当 m=nm=nm=n 时，称为 n 阶方阵。
  • 矩阵的本质: 矩阵描述了一个线性变换。对于 m×nm \times nm×n 矩阵 AAA，其 nnn 个列向量是原空间基向量变换后的坐标，变换后的空间维度是 mmm。
  • 特殊矩阵:
    • 零矩阵 OOO: 所有元素均为 0。
    • 单位矩阵 EEE: 主对角线元素为 1，其余为 0 的方阵。
    • 数量矩阵: 形如 kEkEkE 的方阵。
    • 对角矩阵: 非主对角线元素全为 0 的方阵。
    • 上/下三角矩阵: 主对角线下方/上方元素全为 0 的方阵。
    • 对称矩阵: 满足 AT=AA^T=AAT=A 的方阵 (aij=ajia_{ij}=a_{ji}aij​=aji​)。
    • 反对称矩阵: 满足 AT=−AA^T=-AAT=−A 的方阵 (主对角线元素必为 0)。
