4-3 同解方程组

#线代 #线性方程组 #同解方程组 别名：同解方程组

定义

若两个方程组的解集完全相同，则称它们为同解方程组。

在线代里，初等行变换不会改变方程组的解集，所以化阶梯形的过程，本质上就是把原方程组变成了一个同解方程组。

齐次方程组同解的常用等价条件

对于 AX=0AX=0AX=0 与 BX=0BX=0BX=0，

AX=0 与 BX=0 同解 AX=0 \text{ 与 } BX=0 \text{ 同解} AX=0 与 BX=0 同解

常用等价条件有：

  1. A,BA,BA,B 的行向量组等价。
  2. r(A)=r(B)=r(AB)r(A)=r(B)=r\begin{pmatrix}A\\B\end{pmatrix}r(A)=r(B)=r(AB​)。
  3. r(A)=r(B)r(A)=r(B)r(A)=r(B)，且一个方程组的解必然也是另一个方程组的解。

典型结论

笔记

ATAx=0A^TAx=0ATAx=0 与 Ax=0Ax=0Ax=0 同解。

证明思路：

  1. 若 Ax=0Ax=0Ax=0，两边左乘 ATA^TAT，得 ATAx=0A^TAx=0ATAx=0。
  2. 若 ATAx=0A^TAx=0ATAx=0，左乘 xTx^TxT，得
xTATAx=(Ax)T(Ax)=0 x^TA^TAx=(Ax)^T(Ax)=0 xTATAx=(Ax)T(Ax)=0

而平方和为零只能推出 Ax=0Ax=0Ax=0。

使用场景

  1. 证明两个齐次方程组解集相同。
  2. 先将复杂方程组化简为更容易求解的形式。
  3. 由“同解”反推秩、自由变量个数或基础解系结构。

常用结论

  1. 设矩阵 PPP 列满秩，则 PAx=0PAx=0PAx=0 与 Ax=0Ax=0Ax=0 同解。
  2. ATAx=0A^TAx=0ATAx=0 与 Ax=0Ax=0Ax=0 同解。
  3. 设 AAA 为 nnn 阶矩阵，则 Anx=0A^nx=0Anx=0 与 An+1x=0A^{n+1}x=0An+1x=0 同解。
