协方差

协方差的定义

设 (X,Y)(X,Y)(X,Y) 为二维随机变量, 如果 E{[X−E(X)][Y−E(Y)]}E\{[X-E(X)][Y-E(Y)]\}E{[X−E(X)][Y−E(Y)]} 存在, 则称其为随机变量 XXX 和 YYY的协方差, 记为 Cov(X,Y)\text{Cov}(X,Y)Cov(X,Y), 即

Cov(X,Y)=E{[X−E(X)][Y−E(Y)]}. \text{Cov}(X,Y) = E\{[X-E(X)][Y-E(Y)]\}. Cov(X,Y)=E{[X−E(X)][Y−E(Y)]}.

协方差的计算公式

  1. Cov(X,Y)=E(XY)−E(X)E(Y)\text{Cov}(X,Y) = E(XY) - E(X)E(Y)Cov(X,Y)=E(XY)−E(X)E(Y);
  2. Cov(X,Y)=ρXYD(X)D(Y)\text{Cov}(X,Y) = \rho_{XY} \sqrt{D(X)} \sqrt{D(Y)}Cov(X,Y)=ρXY​D(X)​D(Y)​
  3. Cov(X1+X2,Y1+Y2)=Cov(X1,Y1)+Cov(X1,Y2)+Cov(X2,Y1)+Cov(X2,Y2)\text{Cov}(X_1+X_2, Y_1+Y_2) = \text{Cov}(X_1,Y_1) + \text{Cov}(X_1,Y_2) + \text{Cov}(X_2,Y_1) + \text{Cov}(X_2,Y_2)Cov(X1​+X2​,Y1​+Y2​)=Cov(X1​,Y1​)+Cov(X1​,Y2​)+Cov(X2​,Y1​)+Cov(X2​,Y2​)
  4. Cov(aX,bY)=abCov(X,Y)\text{Cov}(aX, bY) = ab\text{Cov}(X,Y)Cov(aX,bY)=abCov(X,Y)
  5. Cov(X,X)=E(X2)−E(X)2=D(X)\text{Cov}(X,X) =E(X^2)-E(X)^2= D(X)Cov(X,X)=E(X2)−E(X)2=D(X)
  6. 如果 XXX 与 YYY 独立, 则 Cov(X,Y)=0\text{Cov}(X,Y)=0Cov(X,Y)=0.
  7. D(X±Y)=D(X)+D(Y)±2Cov(X,Y)D(X \pm Y) = D(X) + D(Y) \pm 2\text{Cov}(X,Y)D(X±Y)=D(X)+D(Y)±2Cov(X,Y).
  8. D(X1+X2+X3)=D(X1)+D(X2)+D(X3)+2Cov(X1,X2)+2Cov(X1,X3)+2Cov(X2,X3)D(X_1 + X_2 + X_3) = D(X_1) + D(X_2) + D(X_3) + 2\text{Cov}(X_1, X_2) + 2\text{Cov}(X_1, X_3) + 2\text{Cov}(X_2, X_3)D(X1​+X2​+X3​)=D(X1​)+D(X2​)+D(X3​)+2Cov(X1​,X2​)+2Cov(X1​,X3​)+2Cov(X2​,X3​)

协方差的性质

  1. Cov(X,Y)=Cov(Y,X)\text{Cov}(X,Y) = \text{Cov}(Y,X)Cov(X,Y)=Cov(Y,X)
  2. Cov(X,c)=0,c\text{Cov}(X,c) = 0, cCov(X,c)=0,c 为任意常数;

相关系数

相关系数的定义

对于随机变量 XXX 和 YYY, 若 D(X)>0,D(Y)>0D(X)\gt 0, D(Y)\gt 0D(X)>0,D(Y)>0, 则称

ρXY=Cov(X,Y)D(X)D(Y) \rho_{XY} = \frac{\text{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}} ρXY​=D(X)​D(Y)​Cov(X,Y)​

相关系数的性质

  1. ∣ρXY∣≤1|\rho_{XY}| \le 1∣ρXY​∣≤1;
  2. ∣ρXY∣=1|\rho_{XY}|=1∣ρXY​∣=1 的充分必要条件是: 存在常数 a,b(a≠0)a,b(a \ne 0)a,b(a=0) 使
    P{Y=aX+b}=1. P\{Y=aX+b\}=1. P{Y=aX+b}=1.
    且当 a>0a\gt 0a>0 (正相关) 时, ρXY=1\rho_{XY}=1ρXY​=1; 当 a<0a\lt 0a<0 (负相关) 时, ρXY=−1\rho_{XY}=-1ρXY​=−1.

随机变量不相关的定义

如果随机变量 XXX 和 YYY 的相关系数 ρXY=0(Cov(X,Y)=0)\rho_{XY}=0 (\text{Cov}(X,Y)=0)ρXY​=0(Cov(X,Y)=0), 则称 XXX 和 YYY 不相关.

随机变量不相关的等价命题

对于随机变量 X 与 Y, 下面四个结论是等价的

  1. Cov(X,Y)=0\text{Cov}(X,Y) = 0Cov(X,Y)=0;
  2. ρXY=0\rho_{XY}=0ρXY​=0, X 与 Y 不相关;
  3. E(XY)=E(X)E(Y)E(XY) = E(X)E(Y)E(XY)=E(X)E(Y);
  4. D(X±Y)=D(X)+D(Y)D (X \pm Y) = D (X)+D (Y)D(X±Y)=D(X)+D(Y).
随机变量的独立性与不相关性
  1. 若随机变量 XXX 和 YYY 独立, 则 XXX 和 YYY 一定不相关
  2. 若 XXX 和 YYY 不相关, 则不能推出 XXX 和 YYY 相互独立;
  3. 若 XXX 和 YYY 相关, 则一定推出 XXX 和 YYY 不相互独立
  4. 若随机变量 XXX 和 YYY 的联合分布是二维正态分布, 则 XXX 和 YYY 独立等价于 XXX 和 YYY 不相关, 即 ρXY=0\rho_{XY}=0ρXY​=0.
  5. 若随机变量 X 与 Y 都服从 0-1 分布, 则 X 与 Y 独立的充要条件是 X 与 Y 不相关.
