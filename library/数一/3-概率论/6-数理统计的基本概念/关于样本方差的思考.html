关于样本方差的思考

三、为什么 (n−1)S2σ2∼χ2(n−1)\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)σ2(n−1)S2​∼χ2(n−1)？

这个证明主要包含两个部分：

  1. 代数变形：证明 ∑(Xi−Xˉ)2=∑Xi2−nXˉ2\sum (X_i - \bar{X})^2 = \sum X_i^2 - n\bar{X}^2∑(Xi​−Xˉ)2=∑Xi2​−nXˉ2。
  2. 分布推导：证明该式除以 σ2\sigma^2σ2 后服从 χ2(n−1)\chi^2(n-1)χ2(n−1) 分布。

前提假设：设总体 X∼N(μ,σ2)X \sim N(\mu, \sigma^2)X∼N(μ,σ2)，样本 X1,X2,…,XnX_1, X_2, \dots, X_nX1​,X2​,…,Xn​ 独立同分布。

第一部分：代数变形证明

我们需要证明分子部分的恒等式：

∑i=1n(Xi−Xˉ)2=∑i=1nXi2−nXˉ2 \sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2 i=1∑n​(Xi​−Xˉ)2=i=1∑n​Xi2​−nXˉ2

证明步骤：

展开求和符号内部的平方项：

∑i=1n(Xi−Xˉ)2=∑i=1n(Xi2−2XiXˉ+Xˉ2) \begin{aligned} \sum_{i=1}^n (X_i - \bar{X})^2 &= \sum_{i=1}^n (X_i^2 - 2X_i\bar{X} + \bar{X}^2) \end{aligned} i=1∑n​(Xi​−Xˉ)2​=i=1∑n​(Xi2​−2Xi​Xˉ+Xˉ2)​

利用求和符号 ∑\sum∑ 的线性性质，将其拆分为三项：

=∑i=1nXi2−∑i=1n2XiXˉ+∑i=1nXˉ2 = \sum_{i=1}^n X_i^2 - \sum_{i=1}^n 2X_i\bar{X} + \sum_{i=1}^n \bar{X}^2 =i=1∑n​Xi2​−i=1∑n​2Xi​Xˉ+i=1∑n​Xˉ2

逐项分析：

  1. 第一项保持不变：∑i=1nXi2\sum_{i=1}^n X_i^2∑i=1n​Xi2​
  2. 第二项中，2Xˉ2\bar{X}2Xˉ 是常数（相对于求和变量 iii），可以提取出来：
    −2Xˉ∑i=1nXi -2\bar{X} \sum_{i=1}^n X_i −2Xˉi=1∑n​Xi​
    根据均值定义 Xˉ=1n∑Xi\bar{X} = \frac{1}{n}\sum X_iXˉ=n1​∑Xi​，可知 ∑i=1nXi=nXˉ\sum_{i=1}^n X_i = n\bar{X}∑i=1n​Xi​=nXˉ。 所以第二项变为：−2Xˉ⋅(nXˉ)=−2nXˉ2-2\bar{X} \cdot (n\bar{X}) = -2n\bar{X}^2−2Xˉ⋅(nXˉ)=−2nXˉ2。
  3. 第三项是对常数 Xˉ2\bar{X}^2Xˉ2 求和 nnn 次：
    ∑i=1nXˉ2=nXˉ2 \sum_{i=1}^n \bar{X}^2 = n\bar{X}^2 i=1∑n​Xˉ2=nXˉ2

将这三项合并：

∑i=1n(Xi−Xˉ)2=∑i=1nXi2−2nXˉ2+nXˉ2=∑i=1nXi2−nXˉ2 \begin{aligned} \sum_{i=1}^n (X_i - \bar{X})^2 &= \sum_{i=1}^n X_i^2 - 2n\bar{X}^2 + n\bar{X}^2 \\ &= \sum_{i=1}^n X_i^2 - n\bar{X}^2 \end{aligned} i=1∑n​(Xi​−Xˉ)2​=i=1∑n​Xi2​−2nXˉ2+nXˉ2=i=1∑n​Xi2​−nXˉ2​

至此，代数变形得证。

第二部分：统计分布证明

我们需要证明：

∑i=1nXi2−nXˉ2σ2∼χ2(n−1) \frac{\sum_{i=1}^n X_i^2 - n\bar{X}^2}{\sigma^2} \sim \chi^2(n-1) σ2∑i=1n​Xi2​−nXˉ2​∼χ2(n−1)
根据第一部分，这等价于证明 ∑i=1n(Xi−Xˉ)2σ2∼χ2(n−1)\frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} \sim \chi^2(n-1)σ2∑i=1n​(Xi​−Xˉ)2​∼χ2(n−1)。

证明步骤：

  1. 构造恒等式 从标准化变量的平方和入手：∑i=1n(Xi−μ)2\sum_{i=1}^n (X_i - \mu)^2∑i=1n​(Xi​−μ)2。 在括号内配凑 −Xˉ+Xˉ-\bar{X} + \bar{X}−Xˉ+Xˉ：

    ∑i=1n(Xi−μ)2=∑i=1n[(Xi−Xˉ)+(Xˉ−μ)]2 \sum_{i=1}^n (X_i - \mu)^2 = \sum_{i=1}^n [(X_i - \bar{X}) + (\bar{X} - \mu)]^2 i=1∑n​(Xi​−μ)2=i=1∑n​[(Xi​−Xˉ)+(Xˉ−μ)]2

  2. 展开平方项

    =∑i=1n(Xi−Xˉ)2+∑i=1n(Xˉ−μ)2+2(Xˉ−μ)∑i=1n(Xi−Xˉ) = \sum_{i=1}^n (X_i - \bar{X})^2 + \sum_{i=1}^n (\bar{X} - \mu)^2 + 2(\bar{X} - \mu)\sum_{i=1}^n (X_i - \bar{X}) =i=1∑n​(Xi​−Xˉ)2+i=1∑n​(Xˉ−μ)2+2(Xˉ−μ)i=1∑n​(Xi​−Xˉ)
    注意到 ∑i=1n(Xi−Xˉ)=∑Xi−nXˉ=0\sum_{i=1}^n (X_i - \bar{X}) = \sum X_i - n\bar{X} = 0∑i=1n​(Xi​−Xˉ)=∑Xi​−nXˉ=0，所以交叉项为 0。

    于是得到基本恒等式：

    ∑i=1n(Xi−μ)2=∑i=1n(Xi−Xˉ)2+n(Xˉ−μ)2 \sum_{i=1}^n (X_i - \mu)^2 = \sum_{i=1}^n (X_i - \bar{X})^2 + n(\bar{X} - \mu)^2 i=1∑n​(Xi​−μ)2=i=1∑n​(Xi​−Xˉ)2+n(Xˉ−μ)2

  3. 两边除以 σ2\sigma^2σ2 并分析分布

    ∑i=1n(Xi−μ)2σ2=∑i=1n(Xi−Xˉ)2σ2+n(Xˉ−μ)2σ2 \frac{\sum_{i=1}^n (X_i - \mu)^2}{\sigma^2} = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} + \frac{n(\bar{X} - \mu)^2}{\sigma^2} σ2∑i=1n​(Xi​−μ)2​=σ2∑i=1n​(Xi​−Xˉ)2​+σ2n(Xˉ−μ)2​

    整理右边第二项：n(Xˉ−μ)2σ2=(Xˉ−μσ/n)2\frac{n(\bar{X} - \mu)^2}{\sigma^2} = \left( \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \right)^2σ2n(Xˉ−μ)2​=(σ/n​Xˉ−μ​)2。

    现在看各项分布：

    • 等式左边：∑i=1n(Xi−μσ)2\sum_{i=1}^n \left(\frac{X_i-\mu}{\sigma}\right)^2∑i=1n​(σXi​−μ​)2。因为 Xi−μσ∼N(0,1)\frac{X_i-\mu}{\sigma} \sim N(0,1)σXi​−μ​∼N(0,1)，所以左边服从 χ2(n)\chi^2(n)χ2(n)。
    • 等式右边第二项：(Xˉ−μσ/n)2\left( \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \right)^2(σ/n​Xˉ−μ​)2。因为 Xˉ∼N(μ,σ2/n)\bar{X} \sim N(\mu, \sigma^2/n)Xˉ∼N(μ,σ2/n)，标准化后服从 N(0,1)N(0,1)N(0,1)，平方后服从 χ2(1)\chi^2(1)χ2(1)。
    • 等式右边第一项：即我们要求的式子 ∑Xi2−nXˉ2σ2\frac{\sum X_i^2 - n\bar{X}^2}{\sigma^2}σ2∑Xi2​−nXˉ2​。

  4. 利用柯赫伦定理（Cochran's Theorem） 对于正态总体，样本均值 Xˉ\bar{X}Xˉ 与样本方差 S2S^2S2（即 ∑(Xi−Xˉ)2\sum(X_i-\bar{X})^2∑(Xi​−Xˉ)2 部分）是相互独立的。 根据卡方分布的可加性：

    χ2(n)=Y+χ2(1) \chi^2(n) = Y + \chi^2(1) χ2(n)=Y+χ2(1)
    其中 YYY 是未知分布。根据特征函数或可加性性质，必须有：
    Y∼χ2(n−1) Y \sim \chi^2(n-1) Y∼χ2(n−1)

结论：

∑i=1nXi2−nXˉ2σ2∼χ2(n−1) \frac{\sum_{i=1}^n X_i^2 - n\bar{X}^2}{\sigma^2} \sim \chi^2(n-1) σ2∑i=1n​Xi2​−nXˉ2​∼χ2(n−1)
这个结论的关键是“用样本均值Xˉ\bar{X}Xˉ替代了总体均值μ\muμ，引入了1个约束，导致自由度减少1”，推导分3步：

  1. 样本均值的约束：样本均值Xˉ=1n∑i=1nXi\bar{X} = \frac{1}{n}\sum_{i=1}^n X_iXˉ=n1​∑i=1n​Xi​，代入偏差(Xi−Xˉ)(X_i - \bar{X})(Xi​−Xˉ)会满足一个严格约束：
    ∑i=1n(Xi−Xˉ)=0\sum_{i=1}^n (X_i - \bar{X}) = 0i=1∑n​(Xi​−Xˉ)=0

    这意味着n个偏差(X1−Xˉ),(X2−Xˉ),...,(Xn−Xˉ)(X_1 - \bar{X}), (X_2 - \bar{X}), ..., (X_n - \bar{X})(X1​−Xˉ),(X2​−Xˉ),...,(Xn​−Xˉ)中，只要知道n-1个，最后1个就被确定了——独立的偏差只有n-1个。
  2. 样本方差的定义：样本方差S2S^2S2的定义是“除以n-1”（为了无偏估计），即：
    S2=1n−1∑i=1n(Xi−Xˉ)2S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2S2=n−11​i=1∑n​(Xi​−Xˉ)2

    变形可得∑i=1n(Xi−Xˉ)2=(n−1)S2\sum_{i=1}^n (X_i - \bar{X})^2 = (n-1)S^2∑i=1n​(Xi​−Xˉ)2=(n−1)S2。
  3. 自由度调整后的卡方分布：由于偏差(Xi−Xˉ)(X_i - \bar{X})(Xi​−Xˉ)有1个约束，独立的标准化偏差只有n-1个，因此平方和服从自由度为n-1的卡方分布：
    ∑i=1n(Xi−Xˉ)2σ2=(n−1)S2σ2∼χ2(n−1)\frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)σ2∑i=1n​(Xi​−Xˉ)2​=σ2(n−1)S2​∼χ2(n−1)

四、为什么D[(n−1)S2σ2]=2(n−1)D\left[ \frac{(n-1)S^2}{\sigma^2} \right]=2(n-1)D[σ2(n−1)S2​]=2(n−1)且D(S2)=2σ4n−1D(S^2)=\frac{2\sigma^4}{n-1}D(S2)=n−12σ4​？

这是利用了卡方分布的方差性质，推导分2步：

  1. 卡方分布的方差性质：由第三步可知(n−1)S2σ2∼χ2(n−1)\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)σ2(n−1)S2​∼χ2(n−1)，记Y=(n−1)S2σ2Y = \frac{(n-1)S^2}{\sigma^2}Y=σ2(n−1)S2​，则根据卡方分布性质D(Y)=2kD(Y) = 2kD(Y)=2k（k为自由度）：
    D(Y)=D[(n−1)S2σ2]=2(n−1)D(Y) = D\left[ \frac{(n-1)S^2}{\sigma^2} \right] = 2(n-1)D(Y)=D[σ2(n−1)S2​]=2(n−1)
  2. 推导样本方差的方差：根据方差的运算性质D(aX)=a2D(X)D(aX) = a^2D(X)D(aX)=a2D(X)（a为常数），将Y=n−1σ2⋅S2Y = \frac{n-1}{\sigma^2} \cdot S^2Y=σ2n−1​⋅S2代入，其中a=n−1σ2a = \frac{n-1}{\sigma^2}a=σ2n−1​：
    D(Y)=(n−1σ2)2⋅D(S2)D(Y) = \left( \frac{n-1}{\sigma^2} \right)^2 \cdot D(S^2)D(Y)=(σ2n−1​)2⋅D(S2)

    整理得：
    D(S2)=D(Y)⋅σ4(n−1)2=2(n−1)⋅σ4(n−1)2=2σ4n−1D(S^2) = D(Y) \cdot \frac{\sigma^4}{(n-1)^2} = 2(n-1) \cdot \frac{\sigma^4}{(n-1)^2} = \frac{2\sigma^4}{n-1}D(S2)=D(Y)⋅(n−1)2σ4​=2(n−1)⋅(n−1)2σ4​=n−12σ4​
