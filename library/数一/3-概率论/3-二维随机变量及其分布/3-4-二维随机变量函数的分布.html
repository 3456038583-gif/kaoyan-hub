3-4 二维随机变量函数的分布

#概率论 #二维随机变量及其分布

解题方法

  1. 若 Z=g(X,Y)Z=g(X,Y)Z=g(X,Y) 可以视作 XXX 或 YYY 的一次函数, 一般优先用卷积公式来求解.若由 Z=g(X,Y)Z=g(X,Y)Z=g(X,Y) 可求得 Y=h(X,Z)Y=h(X,Z)Y=h(X,Z) (或 X=p(Y,Z)X=p(Y,Z)X=p(Y,Z), 具体看哪种形式计算简便), 则
卷积公式
fZ(z)=∫−∞+∞f(x,h(x,z))∣∂h(x,z)∂z∣dx.f_Z(z) = \int_{-\infty}^{+\infty} f(x, h(x,z)) \left| \frac{\partial h(x,z)}{\partial z} \right| dx.fZ​(z)=∫−∞+∞​f(x,h(x,z))​∂z∂h(x,z)​​dx.

卷积公式中要善于寻找关键点, 对区间进行分段. 需要注意的是卷积公式并不需要 X,YX,YX,Y 相互独立这个条件.

  1. 若 Z=g(X2+Y2)Z=g(X^2+Y^2)Z=g(X2+Y2), 此时卷积公式比较复杂, 更适合用定义法求解.

    FZ(z)=P{Z≤z}=P{g(X2+Y2)≤z},−∞<z<+∞, F_Z(z) = P\{Z \le z\} = P\{g(X^2+Y^2) \le z\}, -\infty \lt z \lt +\infty, FZ​(z)=P{Z≤z}=P{g(X2+Y2)≤z},−∞<z<+∞,
    则 fZ(z)=FZ′(z)f_Z(z) = F'_Z(z)fZ​(z)=FZ′​(z).

  2. 若 Z=g(X,Y)Z=g(X,Y)Z=g(X,Y), 且 (X,Y)(X,Y)(X,Y) 服从二维正态分布, 此时一般只需要计算 ZZZ 的期望和方差, 即可获得 ZZZ 的分布

  • 定义法求解的是分布函数
  • 卷积公式求的是概率密度,

二维随机变量函数的分布函数

设 g(x,y)g(x,y)g(x,y) 是二元函数, 则以随机变量 X,YX,YX,Y 作为变量的函数 Z=g(X,Y)Z=g(X,Y)Z=g(X,Y) 也是随机变量, 称为随机变量 X,YX,YX,Y 的函数, ZZZ 的分布函数为

FZ(z)=P{Z≤z}=P{g(X,Y)≤z},−∞<z<+∞. F_Z(z) = P\{Z \le z\} = P\{g(X,Y) \le z\}, -\infty \lt z \lt +\infty. FZ​(z)=P{Z≤z}=P{g(X,Y)≤z},−∞<z<+∞.

二维随机变量函数的分布函数的求法

二维离散型随机变量函数的分布求法

设 P{X=xi,Y=yj}=pij,Z=g(X,Y)P\{X=x_i, Y=y_j\} = p_{ij}, Z=g(X,Y)P{X=xi​,Y=yj​}=pij​,Z=g(X,Y), 则 ZZZ 的分布律为

P{Z=zk}=P{g(X,Y)=zk}=∑g(xi,yj)=zkP{X=xi,Y=yj}. P\{Z=z_k\} = P\{g(X,Y)=z_k\} = \sum_{g(x_i,y_j)=z_k} P\{X=x_i, Y=y_j\}. P{Z=zk​}=P{g(X,Y)=zk​}=g(xi​,yj​)=zk​∑​P{X=xi​,Y=yj​}.

二维连续型随机变量函数的分布求法

设 (X,Y)(X,Y)(X,Y) 的概率密度为 f(x,y)f(x,y)f(x,y), Z=g(X,Y)Z=g(X,Y)Z=g(X,Y), 则 ZZZ 的分布函数为

FZ(z)=P{Z≤z}=P{g(X,Y)≤z}=∬g(x,y)≤zf(x,y)dxdy, F_Z(z) = P\{Z \le z\} = P\{g(X,Y) \le z\} = \iint_{g(x,y)\le z} f(x,y) dx dy, FZ​(z)=P{Z≤z}=P{g(X,Y)≤z}=∬g(x,y)≤z​f(x,y)dxdy,
若 ZZZ 仍为连续型随机变量, 则 ZZZ 的概率密度为
fZ(z)=FZ′(z). f_Z(z) = F'_Z(z). fZ​(z)=FZ′​(z).

几种常见的二维连续型随机变量函数的分布求解

(1) Z = X + Y 的分布

设 (X,Y)(X,Y)(X,Y) 的概率密度为 f(x,y)f(x,y)f(x,y), 则 Z=X+YZ = X+YZ=X+Y 的密度函数为

fZ(z)=∫−∞+∞f(x,z−x)dx=∫−∞+∞f(z−y,y)dy, f_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x) dx = \int_{-\infty}^{+\infty} f(z-y, y) dy, fZ​(z)=∫−∞+∞​f(x,z−x)dx=∫−∞+∞​f(z−y,y)dy,
当 XXX 与 YYY 独立时, 有
fZ(z)=∫−∞+∞fX(x)fY(z−x)dx=∫−∞+∞fX(z−y)fY(y)dy. f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) dx = \int_{-\infty}^{+\infty} f_X(z-y) f_Y(y) dy. fZ​(z)=∫−∞+∞​fX​(x)fY​(z−x)dx=∫−∞+∞​fX​(z−y)fY​(y)dy.
以上两个公式称为卷积公式, 常记为 fX∗fYf_X * f_YfX​∗fY​.

(2) Z = X/Y 的分布

设 (X,Y)(X,Y)(X,Y) 的概率密度为 f(x,y)f(x,y)f(x,y), 则 Z=XYZ = \frac{X}{Y}Z=YX​ 的密度函数为

fZ(z)=∫−∞+∞∣y∣f(yz,y)dy, f_Z(z) = \int_{-\infty}^{+\infty} |y| f(yz, y) dy, fZ​(z)=∫−∞+∞​∣y∣f(yz,y)dy,
当 XXX 与 YYY 独立时, 有
fZ(z)=∫−∞+∞∣y∣fX(yz)fY(y)dy. f_Z(z) = \int_{-\infty}^{+\infty} |y| f_X(yz) f_Y(y) dy. fZ​(z)=∫−∞+∞​∣y∣fX​(yz)fY​(y)dy.

(3) Z = XY 的分布

设 (X,Y)(X,Y)(X,Y) 的概率密度为 f(x,y)f(x,y)f(x,y), 则 Z=XYZ=XYZ=XY 的密度函数为

fZ(z)=∫−∞+∞1∣y∣f(zy,y)dy=∫−∞+∞1∣x∣f(x,zx)dx, f_Z(z) = \int_{-\infty}^{+\infty} \frac{1}{|y|} f(\frac{z}{y}, y) dy = \int_{-\infty}^{+\infty} \frac{1}{|x|} f(x, \frac{z}{x}) dx, fZ​(z)=∫−∞+∞​∣y∣1​f(yz​,y)dy=∫−∞+∞​∣x∣1​f(x,xz​)dx,
当 XXX 与 YYY 独立时, 有
fZ(z)=∫−∞+∞1∣y∣fX(zy)fY(y)dy=∫−∞+∞1∣x∣fX(x)fY(zx)dx. f_Z(z) = \int_{-\infty}^{+\infty} \frac{1}{|y|} f_X(\frac{z}{y}) f_Y(y) dy = \int_{-\infty}^{+\infty} \frac{1}{|x|} f_X(x) f_Y(\frac{z}{x}) dx. fZ​(z)=∫−∞+∞​∣y∣1​fX​(yz​)fY​(y)dy=∫−∞+∞​∣x∣1​fX​(x)fY​(xz​)dx.

(4) Z = max{X, Y}, Z = min{X, Y} 的分布

设 (X,Y)(X,Y)(X,Y) 的联合分布函数为 F(x,y)F(x,y)F(x,y), XXX 与 YYY 的分布函数分别为 FX(x)F_X(x)FX​(x) 和 FY(y)F_Y(y)FY​(y), 则 Z=max⁡{X,Y},Z=min⁡{X,Y}Z=\max\{X,Y\}, Z=\min\{X,Y\}Z=max{X,Y},Z=min{X,Y} 的分布函数分别为

Fmax⁡(z)=P{max⁡{X,Y}≤z}=P{X≤z,Y≤z}=F(z,z); Fmin⁡(z)=P{min⁡{X,Y}≤z}=P{{X≤z}∪{Y≤z}} =P{X≤z}+P{Y≤z}−P{X≤z,Y≤z} =FX(z)+FY(z)−F(z,z). \begin{aligned} F_{\max}(z) &= P\{\max\{X,Y\} \le z\} = P\{X \le z, Y \le z\} = F(z,z); \ F_{\min}(z) &= P\{\min\{X,Y\} \le z\} = P\{\{X \le z\} \cup \{Y \le z\}\} \ &= P\{X \le z\} + P\{Y \le z\} - P\{X \le z, Y \le z\} \ &= F_X(z) + F_Y(z) - F(z,z). \end{aligned} Fmax​(z)​=P{max{X,Y}≤z}=P{X≤z,Y≤z}=F(z,z); Fmin​(z)​=P{min{X,Y}≤z}=P{{X≤z}∪{Y≤z}} ​=P{X≤z}+P{Y≤z}−P{X≤z,Y≤z} ​=FX​(z)+FY​(z)−F(z,z).​

当 XXX 与 YYY 独立时, 有

Fmax⁡(z)=FX(z)FY(z); Fmin⁡(z)=FX(z)+FY(z)−FX(z)FY(z)=1−[1−FX(z)][1−FY(z)]. \begin{aligned} F_{\max}(z) &= F_X(z)F_Y(z); \ F_{\min}(z) &= F_X(z)+F_Y(z)-F_X(z)F_Y(z) = 1-[1-F_X(z)][1-F_Y(z)]. \end{aligned} Fmax​(z)​=FX​(z)FY​(z); Fmin​(z)​=FX​(z)+FY​(z)−FX​(z)FY​(z)=1−[1−FX​(z)][1−FY​(z)].​

二维混合型随机变量函数的分布求法

所谓混合型, 即为离散型随机变量 XXX 和连续型随机变量 YYY 相结合的情况.

设 XXX 的分布律为 P{X=xi}(i=1,2,… )P\{X=x_i\} (i=1,2,\dots)P{X=xi​}(i=1,2,…), YYY 为连续型随机变量, Z=g(X,Y)Z=g(X,Y)Z=g(X,Y), 则 ZZZ 的分布函数的计算需利用到定义计算:

FZ(z)=P{Z≤z}=P{g(X,Y)≤z} =∑iP{X=xi,g(X,Y)≤z} \begin{aligned} F_Z(z) &= P\{Z \le z\} = P\{g(X,Y) \le z\} \ &= \sum_i P\{X=x_i, g(X,Y) \le z\} \end{aligned} FZ​(z)​=P{Z≤z}=P{g(X,Y)≤z} ​=i∑​P{X=xi​,g(X,Y)≤z}​
其中 P{g(xi,Y)≤z}P\{g(x_i, Y) \le z\}P{g(xi​,Y)≤z} 可由 YYY 的概率密度求得.

独立同分布的可加性计算公式

设随机变量 XXX 与 YYY 相互独立, 则

  1. 若 X∼B(n,p),Y∼B(m,p)X \sim B(n,p), Y \sim B(m,p)X∼B(n,p),Y∼B(m,p), 则 X+Y∼B(n+m,p)X+Y \sim B(n+m, p)X+Y∼B(n+m,p);
  2. 若 X∼P(λ1),Y∼P(λ2)X \sim P(\lambda_1), Y \sim P(\lambda_2)X∼P(λ1​),Y∼P(λ2​), 则 X+Y∼P(λ1+λ2)X+Y \sim P(\lambda_1+\lambda_2)X+Y∼P(λ1​+λ2​);
  3. 若 X∼N(μ1,σ12),Y∼N(μ2,σ22)X \sim N(\mu_1, \sigma_1^2), Y \sim N(\mu_2, \sigma_2^2)X∼N(μ1​,σ12​),Y∼N(μ2​,σ22​), 则 X+Y∼N(μ1+μ2,σ12+σ22)X+Y \sim N(\mu_1+\mu_2, \sigma_1^2+\sigma_2^2)X+Y∼N(μ1​+μ2​,σ12​+σ22​).
