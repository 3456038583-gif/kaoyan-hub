事件的独立性

独立性的定义

  1. 事件 A 与 B 独立 ⇔P(AB)=P(A)P(B)\Leftrightarrow P(AB) = P(A)P(B)⇔P(AB)=P(A)P(B)

    • 事件 A, B 独立指 A 的发生与否对 B 发生的概率无影响。
    • 若 P(B)>0  ⟹  P(A∣B)=P(A)P(B)>0 \implies P(A|B) = P(A)P(B)>0⟹P(A∣B)=P(A)
    • 若 P(A)>0  ⟹  P(B∣A)=P(B)P(A)>0 \implies P(B|A) = P(B)P(A)>0⟹P(B∣A)=P(B)
    • 若 P(A)=0  ⟹  P(AB)=0=0⋅P(B)=P(A)P(B)P(A)=0 \implies P(AB)=0 = 0 \cdot P(B) = P(A)P(B)P(A)=0⟹P(AB)=0=0⋅P(B)=P(A)P(B)

  2. A, B, C 两两独立

    {P(AB)=P(A)P(B),P(AC)=P(A)P(C),P(BC)=P(B)P(C). \begin{cases} P(AB) = P(A)P(B), \\ P(AC) = P(A)P(C), \\ P(BC) = P(B)P(C). \end{cases}⎩⎨⎧​P(AB)=P(A)P(B),P(AC)=P(A)P(C),P(BC)=P(B)P(C).​

  3. A, B, C 相互独立 ⇔\Leftrightarrow⇔

    {P(AB)=P(A)P(B),P(AC)=P(A)P(C),P(BC)=P(B)P(C),P(ABC)=P(A)P(B)P(C). \begin{cases} P(AB) = P(A)P(B), \\ P(AC) = P(A)P(C), \\ P(BC) = P(B)P(C), \\ P(ABC) = P(A)P(B)P(C). \end{cases}⎩⎨⎧​P(AB)=P(A)P(B),P(AC)=P(A)P(C),P(BC)=P(B)P(C),P(ABC)=P(A)P(B)P(C).​
    相互独立强于两两独立

独立性的性质

  1. A 与 B 独立 ⇔\Leftrightarrow⇔ A 与 Bˉ\bar{B}Bˉ 独立 ⇔\Leftrightarrow⇔ Aˉ\bar{A}Aˉ 与 B 独立 ⇔\Leftrightarrow⇔ Aˉ\bar{A}Aˉ 与 Bˉ\bar{B}Bˉ 独立 (四个独立性是等价的)
  2. Ω\OmegaΩ 与 ∅\emptyset∅ 都与任意事件独立；
  3. AAA 与 BBB 相互独立
    ⇔P(AB)=P(A)P(B)⇔P(A∣B)=P(A∣Bˉ)=P(A)(0<P(B)<1)⇔P(B∣A)=P(B∣Aˉ)=P(B)(0<P(A)<1)⇔P(B∣A)+P(Bˉ∣Aˉ)=1(0<P(A)<1);\begin{align*} &\Leftrightarrow P(AB) = P(A)P(B) \\ &\Leftrightarrow P(A|B) = P(A|\bar{B}) = P(A) \quad (0 < P(B) < 1) \\ &\Leftrightarrow P(B|A) = P(B|\bar{A}) = P(B) \quad (0 < P(A) < 1) \\ &\Leftrightarrow P(B|A) + P(\bar{B}|\bar{A}) = 1 \quad (0 < P(A) < 1); \end{align*}​⇔P(AB)=P(A)P(B)⇔P(A∣B)=P(A∣Bˉ)=P(A)(0<P(B)<1)⇔P(B∣A)=P(B∣Aˉ)=P(B)(0<P(A)<1)⇔P(B∣A)+P(Bˉ∣Aˉ)=1(0<P(A)<1);​

    • 其中任意 m(2≤m≤n)m (2 \le m \le n)m(2≤m≤n) 个事件也相互独立；

  5. 若 P(B)≠0P(B) \ne 0P(B)=0, 则事件 A, B 相互独立的充要条件是 P(A∣B)=P(A)P(A | B) = P(A)P(A∣B)=P(A);

  8. 如果 P(A)=0P(A) = 0P(A)=0, 则对任意事件 B 都有 P(AB)=P(A)P(B)P(AB) = P(A)P(B)P(AB)=P(A)P(B), 即 A 与 B 独立;

独立与互斥的关系：

关系辨析
  • 互斥：A,BA, BA,B 有竞争关系，一个发生另一个就不能发生。
  • 独立：A,BA, BA,B 没有关系，一个发生不影响另一个发生的概率。(没有关系就没有影响)
  • A 与 B 独立 ⇔P(AB)=P(A)P(B)\Leftrightarrow P(AB)=P(A)P(B)⇔P(AB)=P(A)P(B)
  • A, B 互斥 ⇔AB=∅⇔P(AB)=0\Leftrightarrow AB = \emptyset \Leftrightarrow P(AB)=0⇔AB=∅⇔P(AB)=0. (若 P(AB)≠0P(AB) \ne 0P(AB)=0, 则 AB≠∅AB \ne \emptysetAB=∅, A, B 不互斥)

但是当 P(A)>0,P(B)>0P(A)>0, P(B)>0P(A)>0,P(B)>0 时，

  • “A, B 独立” 推不出 “A, B 互斥”。

    因为 P(AB)=P(A)P(B)>0P(AB)=P(A)P(B)>0P(AB)=P(A)P(B)>0, A, B 不互斥。

  • “A, B 互斥” 推不出 “A, B 独立”。

    因为 AB=∅  ⟹  P(AB)=0≠P(A)P(B)>0  ⟹  AB = \emptyset \implies P(AB)=0 \ne P(A)P(B) > 0 \impliesAB=∅⟹P(AB)=0=P(A)P(B)>0⟹ A, B 不独立。

独立重复事件与伯努利概型

  • 将只有两个结果 AAA 和 Aˉ\bar{A}Aˉ 的随机试验称为伯努利试验；
  • 若各次试验的结果相互独立称为独立试验；
  • 将一伯努利试验独立重复的进行 nnn 次称为 nnn 重伯努利试验。

在每次试验中，事件 AAA 发生的概率均为 ppp，则在 nnn 次独立重复试验（或 nnn 重伯努利试验）中，事件 AAA 恰好发生 kkk 次的概率为
