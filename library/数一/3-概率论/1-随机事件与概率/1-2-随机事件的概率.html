#概率论 #随机事件与概率 别名：2 随机事件的概率、随机事件的概率

概率与长度、面 (体) 积、质量…是同一类概念，是一种度量。概率是事件 A 出现可能性大小的数值度量，记为 P(A)P(A)P(A)。

概率与条件概率的概念

概率的公理化定义

称 P(A)P(A)P(A) 为事件 AAA 的概率，如果 PPP 满足下列条件：

  1. 非负性 对于每一个事件 AAA，有 P(A)≥0P(A) \ge 0P(A)≥0;
  2. 规范性 对于必然事件 Ω\OmegaΩ，有 P(Ω)=1P(\Omega) = 1P(Ω)=1;
  3. 可列可加性 设事件 A1,⋯ ,An,⋯A_1, \cdots, A_n, \cdotsA1​,⋯,An​,⋯ 两两互不相容，即对于 i≠j,AiAj=∅(i,j=1,2,⋯ )i \ne j, A_i A_j = \emptyset (i,j=1,2,\cdots)i=j,Ai​Aj​=∅(i,j=1,2,⋯)，则 P(A1∪A2∪⋯ )=P(A1)+P(A2)+⋯ ,即P(⋃i=1∞Ai)=∑i=1∞P(Ai).\displaystyle P(A_1 \cup A_2 \cup \cdots) = P(A_1) + P(A_2) + \cdots, \text{即} P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i).P(A1​∪A2​∪⋯)=P(A1​)+P(A2​)+⋯,即P(i=1⋃∞​Ai​)=i=1∑∞​P(Ai​).

概率的计算

1. 直接计算

在某些情况下，利用试验结果的等可能性，可以直接计算随机事件的概率。

古典型概率

如果试验只有 nnn 个基本事件，并且每一个基本事件出现的可能性相同，对于该试验的事件 A，则有

P(A)=A 所包含的基本事件个数 k基本事件的总数 n=kn. P(A) = \frac{\text{A 所包含的基本事件个数 } k}{\text{基本事件的总数 } n} = \frac{k}{n}. P(A)=基本事件的总数 nA 所包含的基本事件个数 k​=nk​.

  • 特征：Ω\OmegaΩ 中的样本点有限，且每个样本点发生的可能性相同。
  • 公式：P(A)=mn\displaystyle P(A) = \frac{m}{n}P(A)=nm​，其中 mmm 为 A 包含的基本事件数，nnn 为 Ω\OmegaΩ 中的基本事件的总数。(计数需注意：防重复、防漏计)
常用结论 (超几何分布)

设 N 件产品中有 M 件次品，从中任取 n 件，则其中恰有 k 件次品的概率为：

P(恰有k件次品)=CMkCN−Mn−kCNn P(\text{恰有k件次品}) = \frac{C_M^k C_{N-M}^{n-k}}{C_N^n} P(恰有k件次品)=CNn​CMk​CN−Mn−k​​

几何型概率

若试验的样本空间是几何区域 (直线、面积或体积)，其度量大小可用 SΩS_\OmegaSΩ​ 表示，且任意点落在度量相同的子区域内是等可能的。当事件 A 为 Ω\OmegaΩ 的某一子区域，其度量为 SAS_ASA​，则事件 A 的概率为

P(A)=SASΩ. P(A) = \frac{S_A}{S_\Omega}. P(A)=SΩ​SA​​.

  • 特征：Ω\OmegaΩ 中样本点无限且构成一个几何区域，且每个样本点的发生是等可能的。
  • 公式：P(A)=L(A)L(Ω)\displaystyle P(A) = \frac{L(A)}{L(\Omega)}P(A)=L(Ω)L(A)​，其中 L(A)L(A)L(A) 和 L(Ω)L(\Omega)L(Ω) 分别表示 A 和 Ω\OmegaΩ 的几何测度（测度为长度或面积等）。
补例

向区间 [0,1][0,1][0,1] 中随机投入一点：

  1. 点恰好落在 x=1/2x=1/2x=1/2 处的概率为 000。
    • 结论：P(A)=0⇏A=∅P(A)=0 \not\Rightarrow A=\emptysetP(A)=0⇒A=∅ (概率为 0 的事件不一定是不可能事件)。
  2. 点落在开区间 (0,1)(0,1)(0,1) 内的概率为 111。
    • 结论：P(B)=1⇏B=ΩP(B)=1 \not\Rightarrow B=\OmegaP(B)=1⇒B=Ω (概率为 1 的事件不一定是必然事件)。
注

① 古典概型与几何概型都有某种等可能性，或者说“均匀性”。两个概型的区别在于：几何概型的样本空间是无限 (不可列) 的，而古典概型的样本空间是有限的。 ② 古典概型问题的主要计算工具是排列和组合，而几何概型问题的主要计算工具是用几何方法计算长度、面积等，也会用到微积分计算。 ③ 古典概型的难点在于当选定样本空间后，正确计算事件 A 所包含样本点的个数；而几何概型难在模型化 (如候车问题、会面问题等)：如何化为数学问题。

2.用频率估计概率

用事件 A 在大量重复试验中出现的频率 fn(A)=A 在 n 次试验中出现的次数 k试验次数 n\displaystyle f_n(A) = \frac{\text{A 在 n 次试验中出现的次数 } k}{\text{试验次数 } n}fn​(A)=试验次数 nA 在 n 次试验中出现的次数 k​ 作为概率 P(A)P(A)P(A) 的近似值。
