1.2.1 凹凸性

提示
  • f′′(x)>0  ⟹  f''(x) > 0 \impliesf′′(x)>0⟹ 曲线是凹的，f′′(x)<0  ⟹  f''(x) < 0 \impliesf′′(x)<0⟹ 曲线是凸的

解释

  • 中点：x1+x22\frac{x_1+x_2}22x1​+x2​​
  • 几何意义
    • 凹
      • 其斜率在增加，即一阶导数在增加 -> 二阶导数大于零；
    • 凸

总结

  • 用一阶导数的正负 -> 判断函数的单调性；
  • 用二阶导数的正负 -> 判断函数的凹凸性；
