10-1 第一型曲线积分

#高数 #线面积分 别名：第一型曲线积分

对弧段的曲线积分，一定大于 0

用于解决不均质光滑曲线的质量问题

∫Lf(x,y)ds\int_L f(x,y)ds∫L​f(x,y)ds

  • f(x,y)f(x,y)f(x,y) 为密度分布，ds为弧长的微元

计算

先代后求 设L的参数方程(α≤t≤β\alpha \le t \le \betaα≤t≤β)

{x=ϕ(t)y=ψ(t)\left\{ \begin{aligned} x=\phi(t)\\ y=\psi(t) \end{aligned} \right.{x=ϕ(t)y=ψ(t)​
则线积分可以转换为普通的定积分

∫Lf(x,y) ds=∫αβf[ϕ(t),ψ(t)](ϕ′(t))2+(ψ′(t))2 dx\int_L f(x,y) \, ds = \int_{\alpha}^\beta f[\phi(t),\psi(t)]\sqrt{ (\phi'(t))^2+(\psi'(t))^2 } \, dx ∫L​f(x,y)ds=∫αβ​f[ϕ(t),ψ(t)](ϕ′(t))2+(ψ′(t))2​dx

(1) 若 L:{x=x(t),y=y(t),α≤t≤βL:\begin{cases} x = x(t), \\ y = y(t), \end{cases} \alpha \le t \le \betaL:{x=x(t),y=y(t),​α≤t≤β, 则

∫Lf(x,y)ds=∫αβf[x(t),y(t)]x′2(t)+y′2(t)dt. \int_L f(x,y)ds = \int_\alpha^\beta f[x(t),y(t)] \sqrt{x'^2(t) + y'^2(t)} dt. ∫L​f(x,y)ds=∫αβ​f[x(t),y(t)]x′2(t)+y′2(t)​dt.

(2) 若 L:y=y(x),a≤x≤bL: y = y(x), a \le x \le bL:y=y(x),a≤x≤b, 则

∫Lf(x,y)ds=∫abf[x,y(x)]1+y′2(x)dx. \int_L f(x,y)ds = \int_a^b f[x,y(x)] \sqrt{1 + y'^2(x)} dx. ∫L​f(x,y)ds=∫ab​f[x,y(x)]1+y′2(x)​dx.

(3) 若 L:r=r(θ),α≤θ≤βL: r = r(\theta), \alpha \le \theta \le \betaL:r=r(θ),α≤θ≤β, 则

∫Lf(x,y)ds=∫αβf(rcos⁡θ,rsin⁡θ)r(θ)2+r(θ)′2dθ. \int_L f(x,y)ds = \int_\alpha^\beta f(r\cos\theta, r\sin\theta) \sqrt{r(\theta)^2 + r(\theta)'^2} d\theta. ∫L​f(x,y)ds=∫αβ​f(rcosθ,rsinθ)r(θ)2+r(θ)′2​dθ.
