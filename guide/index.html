一、3 步快速上手

STEP 01

直接开刷，零门槛

不用注册也能立即使用全部题库、真题解析、单词背诵和原卷 PDF。你的做题记录默认实时保存在本机浏览器中。

登录开启自动云同步

点击顶栏右上角「登录同步」，支持邮箱验证码注册/登录、Google 或 GitHub 一键登录。首次登录会自动把本机已有记录备份到云端。

三、账号登录与云端同步

全自动后台同步，无需手动保存

登录账号后，你在任意页面的记分、错题、单题笔记、词汇生词本和打卡记录都会在停手 2.5 秒后自动同步至 Cloudflare 云端数据库；关闭网页前也会自动兜底补发。换电脑、换手机登录同一个账号即可自动拉取。

五、常见问题

我以前在旧域名 feikntn111.us.ci 上做过题，数据怎么搬到新域名？

旧域名依然保留可访问。你只需打开旧域名进入 /export/ 导出 JSON 备份文件，再回到 kaoyan.feikntn111.com/export/ 导入即可；导入后再登录云端账号，就会自动同步到服务器。

登录之后，我之前在本机做过的题目记录会被清空吗？

不会。首次登录时系统会自动比对本机和云端数据，把本机独有的学习记录合并上传到云端；如果你需要以某一边为准，也可以在右上角账号面板里手动选择「本机覆盖云端」或「云端恢复本机」。

手机端或微信里点 Google 登录打不开怎么办？

Google 官方禁止在微信 / QQ 内置浏览器中进行 OAuth 授权，请点击右上角选择「在 Safari / 系统浏览器中打开」；若当前网络无法直连 Google，可直接使用「邮箱验证码」或「GitHub」登录，同一邮箱会自动归入同一个账号。

退出登录后，本机的学习记录还在吗？

在。退出登录只会清除当前浏览器的登录态并暂停云同步，本机已有的学习记录会完整保留。
