说明

  • 换设备怎么用：在旧设备点「导出全站数据」得到一份 JSON，把文件传到新设备，在新设备打开本页点「从备份恢复」，选中这个文件即可。
  • 恢复是合并的：默认只补本机缺的记录，不会覆盖已有的。想让文件完全取代本机数据，在恢复时勾选「覆盖同名数据」。
  • CSV 只用来查看：总表方便丢进 Excel 排分数、画曲线，但不含完整结构，不能用来恢复。
  • 不含界面偏好：折叠状态、上次看到哪一年这类设置默认不导出，勾选上面的选项可以一并带上。
  • 换了浏览器或清了缓存：浏览器把数据存在本机，清缓存会一并清掉，建议隔一段时间备份一次。
  • 桌面版同样适用：macOS 版把记录存在 App 自己的沙盒里，导出的 JSON 结构与网页版一致，两边可以互相恢复。

离线可用

真题、词汇、知识库全部打包在 App 里，地铁上、图书馆没网也能照常刷题背单词。

和网页同源

用的是同一套内容与同一套记录格式。网页更新后下载新版本即可同步，做题记录仍在本地。

原生窗口

独立应用，不占浏览器标签页，Cmd+Q 干净退出，全屏刷题时界面更安静。

安装

个人自用版本，未做苹果开发者签名
  1. 下载 .dmg 文件，双击打开，把「考研资料总库」拖进「应用程序」文件夹。
  2. 第一次打开时，在「应用程序」里右键点图标 → 打开 → 再点“打开”。直接双击会被系统拦住。
  3. 之后再启动就正常双击即可。做题记录、生词本存在 App 本地，重装不会丢。

如果提示「已损坏，无法打开」，在终端执行 xattr -dr com.apple.quarantine /Applications/KaoyanHub.app 后重开即可。
系统要求：macOS 11 Big Sur 及以上，Apple 芯片（M1 / M2 / M3 / M4）。
