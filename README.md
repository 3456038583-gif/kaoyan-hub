# 考研资料总库

一个纯静态的考研资料站点，把**数学真题与 61 套模拟卷**、**英语真题与一/二刷速查**、**政治真题与肖八**、**2027 红宝书英语词汇**、**考研知识库**以及**数据备份 / macOS 桌面版**整合在同一个入口下。所有页面均为静态 HTML + CSS + JS，无后端、零账号依赖，用户做题记录全部保存在浏览器 `localStorage` 中。

- **线上主站**：<https://kaoyan.feikntn111.us.ci>（短域 <https://k.feikntn111.us.ci>）
- **独立数学站**：<https://math.feikntn111.us.ci>（源码仓库 [kaoyan-math-site](https://github.com/3456038583-gif/kaoyan-math-site)）
- **macOS 桌面版**：见本仓库 [Releases](https://github.com/3456038583-gif/kaoyan-hub/releases/latest) 或站内 `/export/` 下载离线 `.dmg`
- **源码仓库**：<https://github.com/3456038583-gif/kaoyan-hub>（只含网页、脚本与题目数据，不含大体积 PDF）

## 全站外观与全局效率功能

- **6 套全站主题风格**（顶栏「外观」一键切换，全站 337 页同步且零首帧闪烁 + View Transition 跨页平滑过渡）：
  - **经典纸感（Classic）**：暖白宣纸编排，自动跟随系统浅/深色；
  - **液态玻璃（Liquid Glass）** & **暗夜玻璃（Liquid Glass Dark）**：柔和极光背景 + `backdrop-filter` 高透磨砂玻璃与 1px 镜面高光；
  - **静谧深色（Midnight Ink）**：独立手动深色模式，低眩光深夜刷题；
  - **护眼青笺（Eye-Care Sage）**：柔和豆沙青护眼纸面；
  - **水墨宣纸（E-Ink Editorial）**：极简高对比黑白报刊风。
- **阅读字号调节**：外观面板内支持标准 / 舒适 / 大字三档切换，长公式自动横向防溢出滚动。
- **全局命令面板（`⌘K` / `Ctrl+K`）**：随时模糊搜索直达任意科目、61 套模拟卷、错题本、肖八、红宝书、知识库或即时切换主题。
- **跨页专注计时器（倒计时栏 `⏱ 专注`）**：内置 `25分 / 45分 / 60分 / 180分全真模考` 四档预设，跨页保持运行，结束带柔和提示音。
- **阅读进度条与回到顶部**：顶部 2.5px 进度条 + 左下角回到顶部浮钮（自动避让数学右下角浮动得分卡）。

## 数学真题与 61 套模拟卷模块

- **历年真题（2010—2026）**：数一 / 数二 / 数三逐题 LaTeX 还原（KaTeX 本地加载，无需外网），每题附难度星级、考点标注与 B 站「小崔说数」逐题定位视频入口；补充真题覆盖数一/数二/数三 17 年对照表与做题本/解析 PDF。
- **成套模拟卷（共 61 套 / 1,342 题，27,944 段公式 KaTeX 0 报错）**：
  - 2027 李林六套卷（数一/二/三，共 18 套）
  - 2027 李林四套卷（数一/二，共 8 套，含官方勘误修正）
  - 2027 张宇八套卷（数一，8 套）
  - 2027 张宇四套卷（数一/二/三，共 12 套，数三同题搬运校准并补全独有题详解）
  - 2027 崔命六套卷（卷一至卷五 × 数一/二/三，共 15 套）
  - 全站模拟卷解析均已统一清理 `方法一 / 方法二 / 法一 / 法二 / 【注】` 段落分隔，模拟卷列表支持**按套系筛选**与**只看未做**过滤。
- **考场防剧透模式（`🎯 考场防剧透`，快捷键 `E`）**：一键隐藏考点、难度星级、重点标签与同题提示，还原真实考场盲刷体验。
- **高效刷题辅助**：
  - **一键展开 / 收起全部解析** + **题号快速跳转条（1–22）**（高亮错题与已记笔记题号）；
  - **单题个人笔记**：每题下方「笔记」抽屉记录易错点/二级结论，自动保存至 `kaoyanMath.notes.v1` 并随 `/export/` 一并备份；
  - **单题复制（保留 LaTeX）** 与 **复制题图**；
  - **键盘快捷键**：`J` / `K` 上下一题跳转，`E` 切换考场防剧透；
  - **四档计时 & 浮动得分卡 & 成绩统计**：整卷 / 选填 / 大题合计 / 单题计时，同题跨卷自动同步分数，2021 年改革前后分段均分统计。

## 英语、政治、词汇与知识库模块

- **英语真题（`/exam/` & `/english/`）**：英语一 2006—2026、英语二 2010—2026 共 38 套，左右分栏一屏做题、难度标注、逐段精翻、原卷与解析 PDF 预览/下载，以及一刷/二刷速查。

- **知识库（`/library/`）**：Obsidian 笔记预渲染 259 篇，支持全文搜索、双向链接、三科切换与数学/政治专题速查。

## 构建与部署

数据构建脚本与 macOS 桌面版打包工具在同级目录 `../build-tools/`（仓库 [kaoyan-build-tools](https://github.com/3456038583-gif/kaoyan-build-tools)）：

```bash
# 本地预览
cd ~/File_no_iCloud/kaoyan-website/kaoyan-hub
python3 -m http.server 8000

# 部署到 Cloudflare
NODE_OPTIONS=--dns-result-order=ipv4first npx wrangler@latest deploy
```
